# 3. Longest Substring Without Repeating Characters

[Условие на LeetCode](https://leetcode.com/problems/longest-substring-without-repeating-characters/) · **Medium** · Sliding Window, Hash Table

Нужно найти длину самой длинной **подстроки** (непрерывного куска строки), в которой
ни один символ не повторяется.

## Ключевая мысль

**Скользящее окно.** Правая граница идёт по строке, левая только догоняет. Окно всегда
без повторов. Когда справа приходит символ, который уже есть в окне, левую границу ставим
сразу за его прошлое вхождение. Все окна, начинающиеся левее, всё равно содержали бы этот повтор,
поэтому проверять их не нужно.

Словарь `last` хранит последний индекс каждого символа, поэтому прыжок делается за O(1),
а не шагами по одному.

**Ловушка:** символ мог встречаться раньше, но уже **левее окна**. На строке `"abba"` при
второй `a` её прошлый индекс 0, а `left` уже 2. Без проверки `last[ch] >= left` граница
откатилась бы назад, и ответ получился бы 3 вместо 2. Тест на `"abba"` есть в `solution.py`.

## Почему именно так

- **Окно + словарь индексов (выбран).** Один проход, O(n). Левая граница прыгает, а не ползёт.
- **Окно + `set` с удалением слева по одному символу**: тоже O(n), потому что каждый символ
  добавляется и удаляется не больше одного раза. Это классический вариант, но с внутренним `while`.
  Вариант со словарём короче и делает меньше операций.
- **Перебор всех подстрок с проверкой на уникальность**: O(n²) подстрок, каждая проверяется
  до O(n), итого до O(n³). При n порядка 10⁴–10⁵ безнадёжно.
- Массив на 128 ячеек вместо `dict` чуть быстрее в C++/Java, но в Python разницы почти нет,
  а `dict` не зависит от алфавита.

## Сложность

- Время: **O(n)**.
- Память: **O(min(n, k))**, где k — размер алфавита (в словаре не больше различных символов).

## Код

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}
        left = best = 0
        for right, ch in enumerate(s):
            if last.get(ch, -1) >= left:
                left = last[ch] + 1
            last[ch] = right
            best = max(best, right - left + 1)
        return best
```
