# 26. Remove Duplicates from Sorted Array

[Условие на LeetCode](https://leetcode.com/problems/remove-duplicates-from-sorted-array/) · **Easy** · Two Pointers

Дан отсортированный массив. Нужно **на месте** оставить в его начале каждое значение по одному разу,
сохранив порядок, и вернуть количество уникальных значений `k`. Что лежит после первых `k`
элементов, не важно.

## Ключевая мысль

Массив отсортирован, значит одинаковые числа стоят подряд. Новое значение появляется ровно тогда,
когда текущий элемент отличается от **последнего записанного** уникального.

Два указателя: `i` читает массив, `k` указывает, куда писать следующее уникальное значение.
Писатель никогда не обгоняет читателя (`k <= i`), поэтому перезапись не портит ещё не прочитанные данные.

## Почему именно так

- **Два указателя, чтение/запись (выбран).** O(n) по времени, O(1) по памяти, один проход.
  Это ровно то, что требует условие: in-place.
- **`set` / `dict.fromkeys`** даёт уникальные значения за O(n), но с O(n) доп. памяти. Чтобы ответ
  засчитали, всё равно нужно скопировать результат обратно в `nums[:k]`. Нарушает дух in-place.
- **`del nums[i]` / `nums.pop(i)` при каждом дубликате**: каждое удаление сдвигает хвост, итого O(n²).
- Сравнение с `nums[k - 1]`, а не с `nums[i - 1]`: обе версии верны для этой задачи, но первая
  обобщается на задачу 80 (оставить не больше двух копий): там сравнивают с `nums[k - 2]`.

## Сложность

- Время: **O(n)**.
- Память: **O(1)**.

## Код

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        k = 1
        for i in range(1, len(nums)):
            if nums[i] != nums[k - 1]:
                nums[k] = nums[i]
                k += 1
        return k
```
