# 1464. Maximum Product of Two Elements in an Array

[Условие на LeetCode](https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/) · **Easy** · Array

Нужно выбрать два элемента массива с разными индексами так, чтобы произведение `(a - 1) * (b - 1)` было максимальным,
и вернуть это произведение.

## Ключевая мысль

По условию все числа `>= 1`, значит оба множителя `(a - 1)` и `(b - 1)` **неотрицательны**.
Произведение неотрицательных чисел растёт, когда растёт любой из множителей. Поэтому ответ — это
**два наибольших элемента**, и знаки разбирать не нужно.

Два максимума ищем за один проход: новое число больше `first`? Тогда старый `first` становится `second`.
Иначе, если оно больше `second`, обновляем только `second`. Дубликаты обрабатываются сами:
в `[5, 5]` вторая пятёрка попадёт в `second`.

## Почему именно так

- **Один проход с двумя максимумами (выбран).** O(n) по времени, O(1) по памяти.
- **`sorted(nums)[-2:]` / `nums.sort()`**: короче, но O(n log n), а сортировка на месте ещё и меняет
  входной массив. При n ≤ 500 разницы не почувствуешь, но на собеседовании ожидают O(n).
- **`heapq.nlargest(2, nums)`**: O(n), читается хорошо, это нормальный вариант в продакшене.
  Здесь ручной проход показывает, что ты понимаешь, как обновлять два максимума.
- **Перебор всех пар**: O(n²), используется только как эталон в тестах.
- **Если бы числа могли быть отрицательными** (как в похожих задачах), пришлось бы ещё сравнивать
  произведение двух наименьших: минус на минус даёт плюс. Здесь условие это исключает.

## Сложность

- Время: **O(n)**.
- Память: **O(1)**.

## Код

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        first = second = 0
        for v in nums:
            if v > first:
                first, second = v, first
            elif v > second:
                second = v
        return (first - 1) * (second - 1)
```
