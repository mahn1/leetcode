# 2. Add Two Numbers

[Условие на LeetCode](https://leetcode.com/problems/add-two-numbers/) · **Medium** · Linked List, Math

Два неотрицательных числа записаны связными списками цифр, **младший разряд первым**.
Нужно вернуть их сумму в том же формате.

## Ключевая мысль

Обратный порядок цифр — это подарок: списки уже идут от младшего разряда к старшему, ровно в том
порядке, в котором складывают в столбик. Идём по обоим спискам одновременно, складываем цифры
и перенос, записываем `total % 10`, переносим `total // 10`.

Две граничные ситуации закрываются одним условием цикла `while l1 or l2 or carry`:
- списки разной длины: отсутствующая цифра считается нулём;
- перенос после последнего разряда (`5 + 5 = 10`, `999 + 1`) даёт ещё один узел.

## Почему именно так

- **Сложение в столбик за один проход (выбран).** O(max(n, m)) и никаких ограничений на размер чисел.
  `dummy` снова убирает частный случай с головой результата (как в задаче 21).
- **Собрать числа в `int`, сложить, разобрать обратно**: в Python работает благодаря длинной арифметике,
  но это обход задачи. В Java/C++ 100-значное число не влезает ни в один встроенный тип, и на собеседовании
  такой ответ не засчитают. К тому же это три прохода вместо одного.
- **Рекурсия** с передачей переноса: тот же O(n), но O(n) стека без выгоды.
- Новые узлы вместо переиспользования `l1`: входные списки не портятся. Переиспользование экономит
  память, но меняет данные вызывающего кода; для такой задачи это обычно нежелательно.

## Сложность

- Время: **O(max(n, m))**.
- Память: **O(max(n, m))** под результат (доп. память кроме ответа O(1)).

## Код

```python
class Solution:
    def addTwoNumbers(self, l1, l2):
        dummy = tail = ListNode()
        carry = 0
        while l1 or l2 or carry:
            total = carry
            if l1:
                total += l1.val
                l1 = l1.next
            if l2:
                total += l2.val
                l2 = l2.next
            carry, digit = divmod(total, 10)
            tail.next = ListNode(digit)
            tail = tail.next
        return dummy.next
```
