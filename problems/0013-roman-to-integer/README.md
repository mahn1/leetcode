# 13. Roman to Integer

[Условие на LeetCode](https://leetcode.com/problems/roman-to-integer/) · **Easy** · Hash Table, Math, String

Дана корректная римская запись числа от 1 до 3999. Нужно перевести её в целое число.
Используются символы `I`, `V`, `X`, `L`, `C`, `D`, `M`.

## Ключевая мысль

Обычно значения символов складываются: `VII = 5 + 1 + 1 = 7`. Но если меньший
символ стоит перед большим, он вычитается: `IV = 4`, `IX = 9`, `CM = 900`.

Поэтому идём **справа налево** и сравниваем текущее значение с предыдущим символом.
Если текущее меньше, вычитаем его, иначе прибавляем. Например, в `MCMXCIV`
сначала получаем `V - I = 4`, затем `C - X = 90`, затем `M - C = 900`,
а первый символ `M` добавляет ещё 1000. Итог: 1994.

## Почему именно так

- **Словарь + проход справа налево (выбран).** Один проход, сосед справа уже известен,
  поэтому не нужен просмотр вперёд и отдельная обработка конца строки.
- **Проход слева направо со следующим символом.** Тоже O(n), но на каждой итерации
  нужно проверять, существует ли индекс `i + 1`. Код получается длиннее при той же сложности.
- **Замена вычитаемых пар на отдельные символы.** Повторные замены создают новые строки
  и смешивают разбор записи с арифметикой. Прямой проход проще и не изменяет строку.

Словарь даёт значение символа за O(1). Дополнительная память не зависит от длины
строки: в словаре всегда семь пар, а кроме него хранятся только два числа.

## Сложность

- Время: **O(n)**, один проход по строке.
- Память: **O(1)**.

## Код

```python
class Solution:
    def romanToInt(self, s: str) -> int:
        values = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
        total = 0
        previous = 0
        for ch in reversed(s):
            value = values[ch]
            if value < previous:
                total -= value
            else:
                total += value
            previous = value
        return total
```
