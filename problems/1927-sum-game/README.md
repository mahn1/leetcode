# 1927. Sum Game

[Условие на LeetCode](https://leetcode.com/problems/sum-game/) · **Medium** · Game Theory, Math

Строка чётной длины из цифр и `?`. Алиса и Боб по очереди (Алиса первая) заменяют `?` на цифру.
Боб выигрывает, если в конце суммы левой и правой половин равны, иначе выигрывает Алиса.
Нужно определить победителя при оптимальной игре.

## Ключевая мысль

Важна только разность сумм. Пусть `diff` — (сумма левой) − (сумма правой) по известным цифрам,
`ql` и `qr` — число `?` слева и справа.

**1. Нечётное число `?` — Алиса выигрывает.** Последний ход у неё. Перед ним сумма одной половины
фиксирована, а она выбирает одну цифру из 10: как минимум 9 из них дают неравенство.

**2. Чётное число `?`.** Ходы разбиваются на пары «Алиса, затем Боб». Стратегия Боба — **зеркалить**:
- Алиса поставила `a` в ту же половину, где ещё есть `?`. Боб ставит `9 − a` во вторую `?` той же половины.
  Пара добавляет ровно **9** в эту половину.
- Алиса поставила `a` в одну половину, Боб ставит `a` в другую. Пара не меняет разность.

Значит, Боб может гарантировать равенство, только если разность закрывается «девятками»:
лишние `?` одной половины, `(ql − qr)`, разбиваются на `(ql − qr) / 2` пар, каждая даёт +9 этой половине:

```
diff + 9 · (ql − qr) / 2 == 0   ⇔   2·diff + 9·(ql − qr) == 0
```

Если равенство не выполняется, Алиса отклоняет итог крайними ходами (всегда `0` или всегда `9`
в нужную половину), и Боб не успевает компенсировать. Формулу на маленьких строках проверяет
честный минимакс в тестах.

## Почему именно так

- **Формула за O(n) (выбран).** Один проход по строке, без перебора. Это нормально для игровых задач:
  находим инвариант (здесь «пара ходов = ровно 9») и доказываем стратегию для обоих игроков.
- **Минимакс с мемоизацией по `(diff, ql, qr)`** честный, но состояний порядка n² · 9n, при n до 10⁵
  это безнадёжно. Он оставлен в `solution.py` только как эталон для тестов.
- **Жадная симуляция** («Алиса ставит 9 в бóльшую половину, Боб отвечает…») легко ошибается:
  оптимальная игра зависит от того, кто сможет ответить последним, а не от того, кто сходит жаднее.
- Умножение на 2 вместо деления `(ql − qr) / 2` убирает дробные числа: при чётном общем числе `?`
  разность `ql − qr` тоже чётная, но так код надёжнее.

## Сложность

- Время: **O(n)**.
- Память: **O(1)**.

## Код

```python
class Solution:
    def sumGame(self, num: str) -> bool:
        half = len(num) // 2
        diff = 0
        q_diff = 0
        for i, ch in enumerate(num):
            sign = 1 if i < half else -1
            if ch == "?":
                q_diff += sign
            else:
                diff += sign * int(ch)
        if num.count("?") % 2:
            return True
        return 2 * diff + 9 * q_diff != 0
```
