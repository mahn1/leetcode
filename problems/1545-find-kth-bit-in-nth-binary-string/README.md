# 1545. Find Kth Bit in Nth Binary String

[Условие на LeetCode](https://leetcode.com/problems/find-kth-bit-in-nth-binary-string/) · **Medium** · Recursion, Divide and Conquer

Строки строятся рекурсивно: `S1 = "0"`, а каждая следующая — это предыдущая, затем `"1"`, затем
предыдущая, инвертированная и развёрнутая. Нужно вернуть `k`-й бит строки `Sn`.

## Ключевая мысль

У `Sn` длина `2^n − 1`, а середина стоит на позиции `mid = 2^(n−1)`. Строка состоит из трёх частей:

```
S_n = [ S_{n-1} ]  "1"  [ reverse(invert(S_{n-1})) ]
        1..mid−1   mid        mid+1..2^n−1
```

- `k == mid`: ответ `"1"`;
- `k < mid`: это тот же бит, что `k`-й в `S_{n−1}`;
- `k > mid`: правая часть — зеркало левой с инверсией. Позиция `k` соответствует позиции
  `2^n − k` в `S_{n−1}`, а бит надо **инвертировать**.

Спускаемся так до `S1 = "0"` и считаем, сколько раз попали в правую половину (чётность инверсий).
Строку не строим вообще.

## Почему именно так

- **Спуск по половинам (выбран).** O(n) шагов и O(1) памяти. Цикл вместо рекурсии: та же логика,
  без стека вызовов.
- **Построить `Sn` и взять `[k−1]`**: при n = 20 строка длиной около 10⁶ символов, плюс все промежуточные
  строки. В лимиты это укладывается, но O(2^n) там, где хватает O(n). При n = 40 такой подход уже невозможен.
- **Рекурсия `f(n, k)`** с теми же тремя случаями: эквивалентна, глубина всего n ≤ 20, так что тоже
  нормально. Итеративная версия показывает, что рекурсия хвостовая и разворачивается в цикл.
- Формула зеркала: длина `L = 2^n − 1`, отражение позиции `k` — это `L + 1 − k = 2^n − k`.
  Здесь легко ошибиться на единицу, поэтому тесты сверяют **все** `k` для n до 10.

## Сложность

- Время: **O(n)**.
- Память: **O(1)**.

## Код

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        flip = 0
        while n > 1:
            mid = 1 << (n - 1)
            if k == mid:
                return str(1 ^ flip)
            if k > mid:
                k = (1 << n) - k
                flip ^= 1
            n -= 1
        return str(flip)
```
