# 6. Zigzag Conversion

[Условие на LeetCode](https://leetcode.com/problems/zigzag-conversion/) · **Medium** · String, Simulation

Строку записывают зигзагом на `numRows` строках: вниз по столбцу, затем по диагонали вверх и снова вниз.
Нужно вернуть результат, прочитанный построчно сверху вниз.

## Ключевая мысль

Горизонтальные позиции (столбцы) **не важны**: при построчном чтении важно только, в какую
**строку** попал символ и в каком порядке. Поэтому сетку не строим, а идём по символам и
«катаемся» указателем строки: `0, 1, …, numRows−1, numRows−2, …, 1, 0, 1, …`.
На верхней и нижней строке меняем направление. В конце склеиваем строки.

```
numRows = 4:  строки по символам  0 1 2 3 2 1 0 1 2 3 2 1 0 1
              P A Y P A L I S H I R I N G
```

Особый случай `numRows == 1`: без него `step` колебался бы на одной строке, и индекс вышел бы за границы.

## Почему именно так

- **Симуляция по строкам (выбран).** O(n) по времени, O(n) по памяти под результат. Не надо
  вычислять индексы, легко объяснить и сложно ошибиться.
- **Формула через период** `cycle = 2·(numRows − 1)`: строка `r` содержит индексы
  `i ≡ r` и `i ≡ cycle − r (mod cycle)`. Тоже O(n), если ходить по индексам шагами `cycle`, и без
  промежуточных списков. Но больше граничных случаев (первая и последняя строки берут по одному символу на период).
  В тестах используется как независимый эталон.
- **Строить двумерную сетку** `numRows × столбцы` и читать её: O(numRows · n) памяти, почти вся
  сетка пустая. Лишняя работа ради картинки, которая не нужна.
- Списки и `"".join` вместо `rows[r] += ch`: конкатенация строк в цикле в общем случае
  квадратична. `join` один раз собирает результат.

## Сложность

- Время: **O(n)**.
- Память: **O(n)** под строки результата.

## Код

```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        if numRows == 1 or numRows >= len(s):
            return s
        rows = [[] for _ in range(numRows)]
        row, step = 0, 1
        for ch in s:
            rows[row].append(ch)
            if row == 0:
                step = 1
            elif row == numRows - 1:
                step = -1
            row += step
        return "".join("".join(r) for r in rows)
```
