# 217. Contains Duplicate

[LeetCode](https://leetcode.com/problems/contains-duplicate/) ⭐Easy⭐ Hash Table

Дан целочисленный массив `nums`. Верните `True`, если какое-либо значение встречается в массиве хотя бы дважды, и `False`, если все элементы уникальны.

**Пример 1:**

```
Вход: nums = [1,2,3,1]
Выход: true
```

**Пример 2:**

```
Вход: nums = [1,2,3,4]
Выход: false
```

**Пример 3:**

```
Вход: nums = [1,1,1,3,3,4,3,2,4,2]
Выход: true
```

**Ограничения:**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## Ключевая мысль

Достаточно запоминать уже встреченные числа в множестве `set`. Проверка «есть ли число в множестве» и вставка в среднем выполняются за O(1).

## Почему именно так

- Если пройти по массиву и складывать элементы в `set`, то при повторном появлении числа мы это сразу обнаружим и вернём `True`.
- Если дошли до конца без повторов — все элементы уникальны, возвращаем `False`.

## Почему именно так, а не короче (`len(nums) != len(set(nums))`, сортировка)

- Сравнение `len(nums) != len(set(nums))` — лаконично: O(n) на построение множества, но создаёт копию всех элементов сразу, без раннего выхода. Наш вариант может остановиться на первом повторении.
- Сортировка и соседние элементы — O(n log n), медленнее, плюс изменяет/копирует массив.

**Почему цикл кончен:** в массиве `n` чисел, поэтом�� не более `n + 1` шагов, по каждому числу проходим ровно один раз. Значит, шагов не больше `n`.

## Почему именно так:

- **`set` + перебор.** O(n) на построение множества и O(n) шагов перебора.
- **Проверка `m in nums` по списку:** каждый проход O(n), итого O(n²). При n ≥ 10^5 это уже тяжело, но проверка приоритета через `set` важнее для задач большего размера.
- **Отфильтровать крайние `k`, отсортировать и искать первое «дыру»:** O(n log n), и легко ошибиться с дубликатами (`[3, 3, 6]`). Перебор проще и быстрее.
- **Битовый массив на 101 ячейку** вместит `set`: работает благодаря маленьким ограничениям, но привязывает код к `nums[i] <= 100`. `set` от ограничений не зависит.

## Сложность

- Время: **O(n)** — один проход по массиву.
- Память: **O(n)** — под множество `seen`.

## Код

```python
from typing import List


class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        seen = set()
        for num in nums:
            if num in seen:
                return True
            seen.add(num)
        return False
```
