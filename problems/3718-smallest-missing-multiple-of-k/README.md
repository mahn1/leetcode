# 3718. Smallest Missing Multiple of K

[Условие на LeetCode](https://leetcode.com/problems/smallest-missing-multiple-of-k/) · **Easy** · Hash Table

Дан массив чисел и число `k`. Нужно найти наименьшее положительное кратное `k`, которого нет в массиве.

## Ключевая мысль

Перебираем кратные по возрастанию: `k, 2k, 3k, …`, и возвращаем первое, которого нет в массиве.
Чтобы проверка «есть ли число в массиве» стоила O(1), кладём массив в `set`.

**Почему цикл конечен:** в массиве `n` чисел, поэтому из `n + 1` кратных `k, 2k, …, (n+1)k`
хотя бы одного нет (принцип Дирихле). Значит, шагов не больше `n + 1`.

## Почему именно так

- **`set` + перебор кратных (выбран).** O(n) на построение множества и O(n) шагов перебора.
- **Перебор с `m in nums` по списку**: каждая проверка O(n), итого O(n²). При n ≤ 100 тоже пройдёт,
  но привычка проверять принадлежность через `set` важнее для задач побольше.
- **Отфильтровать кратные `k`, отсортировать и искать первую «дыру»**: O(n log n), и легко ошибиться
  с дубликатами (`[3, 3, 6]`). Перебор проще и быстрее.
- **Битовый массив на 101 ячейку** вместо `set`: работает благодаря маленьким ограничениям,
  но привязывает код к `nums[i] <= 100`. `set` от ограничений не зависит.

## Сложность

- Время: **O(n)**.
- Память: **O(n)** под множество.

## Код

```python
class Solution:
    def missingMultiple(self, nums: List[int], k: int) -> int:
        seen = set(nums)
        m = k
        while m in seen:
            m += k
        return m
```
