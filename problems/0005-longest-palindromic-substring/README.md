# 5. Longest Palindromic Substring

[Условие на LeetCode](https://leetcode.com/problems/longest-palindromic-substring/) · **Medium** · Two Pointers, String

Нужно вернуть самую длинную подстроку, которая читается одинаково слева направо и справа налево.

## Ключевая мысль

У каждого палиндрома есть **центр**, и от центра он симметричен. Значит, можно перебрать центры
и от каждого расширяться двумя указателями в стороны, пока символы по краям совпадают.

Центров `2n - 1`:
- символ, для нечётной длины: `"aba"`, центр `b`;
- промежуток между соседями, для чётной длины: `"abba"`, центр между двумя `b`.

Если забыть про чётные центры, решение вернёт `"b"` вместо `"bb"` на `"cbbd"`.

## Почему именно так

- **Расширение от центра (выбран).** O(n²) по времени и O(1) по памяти. Короткий код,
  легко объяснить, и на практике быстрый: на строках без длинных палиндромов расширение
  обрывается почти сразу.
- **Динамика `dp[i][j]`** (подстрока `s[i..j]` палиндром, если края равны и `dp[i+1][j-1]` верно):
  тоже O(n²) по времени, но O(n²) по памяти. Для n = 1000 это миллион ячеек, а в Python ещё и медленно.
  Никакого выигрыша по сравнению с центрами.
- **Перебор всех подстрок с проверкой**: O(n³), при n = 1000 это порядка 10⁹ операций.
- **Алгоритм Манакера**: O(n), асимптотически лучший. Но его сложно написать без ошибок, и при
  n ≤ 1000 он не нужен. Стоит упомянуть на собеседовании как следующий шаг.

## Сложность

- Время: **O(n²)**: 2n − 1 центров, каждое расширение до O(n).
- Память: **O(1)**, кроме самого ответа.

## Код

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(left: int, right: int) -> tuple:
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            return left + 1, right

        start, end = 0, 1
        for c in range(len(s)):
            for lo, hi in (expand(c, c), expand(c, c + 1)):
                if hi - lo > end - start:
                    start, end = lo, hi
        return s[start:end]
```
