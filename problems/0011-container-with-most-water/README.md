# 11. Container With Most Water

[Условие на LeetCode](https://leetcode.com/problems/container-with-most-water/) · **Medium** · Two Pointers, Greedy

Дан массив высот вертикальных линий. Две линии и ось X образуют контейнер.
Нужна максимальная площадь воды, которую он может удержать.
Площадь пары `(i, j)` равна `min(height[i], height[j]) * (j - i)`.

## Ключевая мысль

Самая широкая пара — это края массива. Дальше ширина только уменьшается,
поэтому новая пара может быть лучше, только если вырастет **меньшая** из двух высот:
именно она ограничивает уровень воды.

Два указателя стоят на краях. На каждом шаге считаем площадь и сдвигаем указатель
у более низкой линии. Более высокую трогать бессмысленно: ширина станет меньше,
а уровень воды всё равно упрётся в низкую линию, так что площадь не вырастет.

Если высоты равны, сдвиг любой стороны корректен. Вторая сторона с той же высотой
не даст большей площади при меньшей ширине, а все пары между текущими границами
ещё будут рассмотрены, пока указатели не сойдутся.

## Почему именно так

- **Два указателя с краёв (выбран).** Каждый указатель двигается только внутрь,
  шагов не больше n. Оптимум не пропускается: отброшенные пары имели ту же
  или меньшую ограничивающую высоту и меньшую ширину.
- **Все пары.** O(n²) площадей. При n до 10⁵ это уже не проходит по времени.
- **Для каждой левой границы бинарный поиск правой.** Площадь не монотонна
  по правой границе (высоты скачут), так что бинпоиск здесь не к чему применить.

## Сложность

- Время: **O(n)**.
- Память: **O(1)**.

## Код

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        best = 0
        while left < right:
            h = min(height[left], height[right])
            best = max(best, h * (right - left))
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return best
```
