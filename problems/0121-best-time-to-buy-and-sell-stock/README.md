# 121. Best Time to Buy and Sell Stock

[Условие на LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/) · **Easy** · Array, Greedy

Дан массив цен акции по дням. Нужно выбрать один день покупки и один более поздний
день продажи так, чтобы прибыль была максимальной. Если прибыльной сделки нет,
ответ 0. Покупать и продавать в один день нельзя, сделка ровно одна.

## Ключевая мысль

Для продажи в день `i` лучшая покупка — это **минимум цен на отрезке `[0, i]`**.
Более ранняя цена уже учтена в этом минимуме, более поздняя ещё не наступила
и для этой продажи запрещена.

Идём слева направо, держим `low` — минимум слева, включая текущий день.
Прибыль дня равна `price - low`. Покупка «сегодня и продажа сегодня» даёт 0
и ответ не портит: минимум обновляется после сравнения, но даже если обновить
раньше, разность текущего дня с самим собой нулевая.

Если массив строго убывает, `price - low` никогда не больше нуля, и ответ остаётся 0.

## Почему именно так

- **Минимум слева + один проход (выбран).** O(n) по времени, O(1) по памяти.
  Каждая продажа сразу сравнивается со своей лучшей покупкой.
- **Все пары дней.** O(n²). При n до 10⁵ не укладывается.
- **Кадане на массиве разностей `prices[i] - prices[i - 1]`.** Тоже O(n):
  максимальная прибыль — это максимальная сумма непрерывного куска дневных
  изменений. Тот же ответ, но через лишний массив и менее прямую формулировку.
  Минимум слева читается из условия буквально.
- **Стек «следующий больший»** здесь не нужен: нас интересует не ближайший рост,
  а глобальный максимум разности с любым прошлым минимумом.

## Сложность

- Время: **O(n)**.
- Память: **O(1)**.

## Код

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        low = prices[0]
        best = 0
        for price in prices:
            best = max(best, price - low)
            low = min(low, price)
        return best
```
