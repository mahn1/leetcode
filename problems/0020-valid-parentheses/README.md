# 20. Valid Parentheses

[Условие на LeetCode](https://leetcode.com/problems/valid-parentheses/) · **Easy** · Stack

Дана строка из скобок трёх видов. Нужно проверить, что каждая скобка закрыта парной скобкой того же вида
и в правильном порядке.

## Ключевая мысль

Закрывающая скобка всегда должна соответствовать **последней ещё не закрытой** открывающей.
«Последний пришёл — первый ушёл» — это стек: открывающие кладём, на закрывающей снимаем вершину
и сверяем вид. В конце стек должен быть пуст.

## Почему именно так

- **Стек (выбран).** Один проход, каждый символ кладётся и снимается не больше одного раза.
  Ловит все виды ошибок: не тот вид (`(]`), неверный порядок (`([)]`), лишняя закрывающая (`]`)
  и незакрытая открывающая (`((`).
- **Счётчики для каждого вида скобок** не работают: на `([)]` все счётчики сходятся в ноль,
  но порядок нарушен. Счётчиком можно обойтись только когда вид скобок один.
- **Повторное удаление пар** (`while "()" in s: s = s.replace("()", "")` и т. д.): код короткий,
  но O(n²), потому что каждая замена создаёт новую строку.
- Словарь `закрывающая -> открывающая` вместо цепочки `if` одновременно отличает закрывающие
  скобки от открывающих (`ch in pairs`) и даёт пару за O(1).

## Сложность

- Время: **O(n)**, один проход.
- Память: **O(n)** под стек в худшем случае (строка из одних открывающих).

## Код

```python
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {")": "(", "]": "[", "}": "{"}
        stack = []
        for ch in s:
            if ch in pairs:
                if not stack or stack.pop() != pairs[ch]:
                    return False
            else:
                stack.append(ch)
        return not stack
```
