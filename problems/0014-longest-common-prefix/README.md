# 14. Longest Common Prefix

[Условие на LeetCode](https://leetcode.com/problems/longest-common-prefix/) · **Easy** · String

Нужно найти самое длинное начало, общее для всех строк массива. Если его нет, вернуть пустую строку.

## Ключевая мысль

Общий префикс — это **столбцы**, в которых у всех строк стоит одна и та же буква.
Достаточно идти по позициям слева направо и остановиться на первом столбце, где буквы разошлись
или какая-то строка закончилась.

## Почему именно так

- **Вертикальный проход (выбран).** Останавливаемся на первом расхождении, поэтому лишние символы
  не читаем. `zip(*strs)` сам обрезает перебор по самой короткой строке, отдельная проверка
  границ не нужна. Худший случай O(S), где S — суммарная длина строк, и это нижняя граница:
  меньше любой ответ не прочитает.
- **Горизонтальный проход** (взять `strs[0]` и укорачивать его, сравнивая с каждой строкой):
  тоже O(S), но если общий префикс короткий, а первая строка длинная, он сначала тратит
  сравнения на `strs[0]` целиком. Вертикальный обрывается сразу.
- **Сортировка + сравнение первой и последней строки:** короткий код, но O(S·log n) из-за
  сортировки. Без сортировки, через `min()` и `max()`, будет O(S): префикс самой меньшей
  и самой большой строки общий для всех. Хорошая идея для собеседования, но менее очевидная.
- **Trie:** O(S) по времени и O(S) по памяти. Окупается, только если запросов много.
  Для одного запроса это перебор.

## Сложность

- Время: **O(S)**, где S — суммарная длина всех строк (в худшем случае, когда все строки одинаковые).
- Память: **O(m)** под ответ, где m — длина префикса; `zip` ленивый.

## Код

```python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        prefix = []
        for chars in zip(*strs):
            if len(set(chars)) != 1:
                break
            prefix.append(chars[0])
        return "".join(prefix)
```
